# Task4Advanced — агрегаты (границы, инварианты, ключи)

Агрегат — граница транзакционной согласованности: изменения внутри атомарны,
наружу публикуются события. Идентификация — глобальный ключ (UUID/aggregatId),
ссылки между агрегатами — только по идентификатору.

| Домен | Агрегат | Ключ | Граница (что внутри) | Ключевые инварианты | Публикует |
|---|---|---|---|---|---|
| Клиники | **Пациент** | patientId | Ф.И.О., контакты, согласия, статус онбординга | уникальный контактный идентификатор; согласия актуальны; изменившиеся данные версионированы | `PatientRegistered`, `PatientConsentChanged` |
| Клиники | **Приём (Visit)** | visitId | слот, пациент, специалист, статус, результаты без PHI-деталей | приём принадлежит одному пациенту; смена статуса — только по разрешённым переходам (назначен → завершён/отменён) | `VisitScheduled`, `VisitCompleted`, `VisitCancelled` |
| Клиники | **Медицинская карта** | recordId | карта, исследования (ИЗОЛИРОВАННЫЙ контекст) | доступ только лечащей бригаде; наружу — только факты без PHI | `StudyCompleted` (обезличенный факт) |
| ИИ-сервисы | **Исследование ИИ** | studyId | запрос, модель+версия, статус, результат | результат валиден только для указанной версии модели; повторный прогон — новое исследование | `AIStudyPassed`, `AIDiagnosisConfirmed` |
| ИИ-сервисы | **ML-модель** | modelId | версия, датасет (обезличенный), метрики, статус | в проде только модели с пройденным валидационным гейтом | `ModelPromoted` |
| Финтех | **Кредитная заявка** | applicationId | анкета, скоринг, статус | решение только по завершённому скорингу; одна активная заявка на клиента/продукт | `CreditApplicationSubmitted`, `CreditDecisionMade` |
| Финтех | **Кредитный договор** | contractId | условия, график, обеспечение | изменение условий — допсоглашение (новое событие); график консистентен сумме | `CreditContractCreated`, `PaymentScheduleChanged` |
| Финтех | **Платёж** | paymentId | счёт, сумма, статус, проводки | идемпотентность по ключу операции; двойное проведение запрещено | `PaymentCompleted`, `PaymentFailed` |
| Головной офис | **Финансовый период** | periodId | консолидированные проводки, статус закрытия | закрытый период неизменяем | `PeriodClosed` |
| Головной офис | **Сотрудник / Единица инвентаря** | employeeId / assetId | кадровые данные, назначения, оборудование | назначение оборудования — через сотрудника (одна точка владения) | `EmployeeHired`, `AssetAssigned` |

Правила взаимодействия: агрегат не читает другой агрегат напрямую — получает
события или запрашивает через API домена; витрина данных потребляет только
события/data products и не владеет агрегатами.
