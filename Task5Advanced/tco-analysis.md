# Task5Advanced — TCO-анализ (текущая vs целевая архитектура, 3 года)

Оценки в условных единицах (у.е. = 100 тыс ₽/мес), консервативные, для
сравнения пропорций. Горизонт: 36 месяцев.

## Статьи затрат

| Статья | As-Is (Camel + DWH SQL 2008 + PB + BI-кастомизации), у.е./мес | To-Be (облако, события, Lakehouse, витрина, домены), у.е./мес | Комментарий |
|---|---|---|---|
| Инфраструктура (серверы/ЦОД/облако) | 180 | 120 | уход от старого железа и его амортизации; облако pay-as-you-go, автомасштаб |
| Лицензии (SQL Server, PowerBuilder, ОС) | 150 | 30 | открытое ядро (Postgres, Iceberg, Kafka-аналоги); лицензии остаются только в финтех-контуре до миграции |
| Сопровождение легаси (поддержка SQL 2008/PB, риски EOL) | 140 | 20 (снижается поэтапно) | расширенная поддержка EOL-стека дороже год от года; после вывода — 0 |
| Команда хранилища/интеграций (центральная) | 200 | 60 | вместо одной перегруженной команды — платформенная команда меньшего размера |
| Доменные команды данных (Data Engineers/владельцы продуктов) | 40 | 170 | перераспределение: люди ближе к бизнесу, эффект выше |
| Время аналитиков (ожидание отчётов, ручные доработки) | 160 | 40 | self-service: часы вместо недель; near-real-time витрины |
| Потери от инцидентов/простоев DWH и медленных релизов | 120 | 45 | изоляция сбоев, отказоустойчивость облака, независимые релизы доменов |
| **Итого/мес** | **990** | **485** | |
| **Итого 3 года** | **~35 640** | **~17 460 + разовые** | |

| Инвестиция | у.е. | Момент |

## Итог

- As-Is за 3 года: ~35 600 у.е.
- To-Be: 17 460 (операционные) + 3 500 (инвестиции) ≈ **21 000 у.е.**
  → экономия ~40% на горизонте 3 лет, при этом:
  - отчёты: часы → секунды/минуты (near-real-time);
  - TTM новых направлений: месяцы → недели (подключение событиями);
  - устранён риск EOL SQL Server 2008 (растущая цена поддержки).

Точка перелома (окупаемость инвестиций) — ~14–16 месяц, что совпадает
с этапом 2 (масштабирование на критические домены).
