# Task5Advanced — расширенный технический радар (таблица-дубль диаграммы)

Диаграмма: `tech-radar.drawio`. Квадранты: языки/фреймворки, практики
и паттерны (включая архитектурные паттерны), платформы и данные, инструменты.

| Технология / паттерн | Квадрант | Кольцо | Обоснование |
|---|---|---|---|
| Go | Языки | **Adopt** | финтех-сервисы кейса, штатная экспертиза |
| Java 17+ | Языки | **Adopt** | стабильные доменные сервисы |
| Python (ML) | Языки | **Adopt** | ИИ-сервисы кейса |
| React | Языки | **Adopt** | витрина самообслуживания |
| PowerBuilder | Языки | **Hold** | легаси-UI клиник, вывод по этапу 3 |
| T-SQL бизнес-логика DWH | Практики | **Hold** | логика переносится в домены, DWH → мост |
| Event-Driven Architecture | Практики | **Adopt** | целевая слабосвязанная платформа кейса |
| DDD / Bounded Contexts | Практики | **Adopt** | границы доменов (финтех/клиники/ИИ/офис) |
| Data Mesh | Практики | **Trial** | пилот на 1–2 доменах (этап 1 кейса) |
| Self-service BI | Практики | **Trial** | витрина v1 на пилоте, масштабирование — этап 2 |
| Data Contracts | Практики | **Assess** | стандарты и CI-проверки — этапы 1–2 |
| Kafka | Платформы | **Adopt** | шина событий, DLQ, каталог схем |
| Kubernetes | Платформы | **Adopt** | стек компании, среды доменов в облаке |
| PostgreSQL | Платформы | **Adopt** | OLTP доменов |
| Lakehouse (S3 + Iceberg) | Платформы | **Trial** | платформа данных: raw/curated, время-путешествия |
| Nessie-каталог | Платформы | **Trial** | ветки данных для экспериментов |
| Потоковые витрины | Платформы | **Assess** | near-real-time — этап 2 |
| Camel ESB | Платформы | **Hold** | мост совместимости за антикоррупционным слоем |
| SQL Server 2008 DWH | Платформы | **Hold** | CDC-источник и мост, вывод по TIME |
| Terraform | Инструменты | **Adopt** | IaC сред доменов (Task1–2) |
| GitHub Actions | Инструменты | **Adopt** | CI/CD инфраструктуры и data contracts |
| DataHub | Инструменты | **Adopt** | каталог: поиск, lineage, политики |
| Dremio/Trino | Инструменты | **Trial** | SQL-движок витрины поверх Iceberg |
| Great Expectations | Инструменты | **Assess** | качество данных в пайплайнах |
| OpenLineage | Инструменты | **Trial** | происхождение пайплайнов в каталог |

Движения за последний пересмотр: Data Mesh, Lakehouse, Self-service BI,
Nessie — вперёд (Trial); PowerBuilder, Camel, SQL Server 2008 — вывод (Hold);
Go/Java/Python — без изменений. Горизонт пересмотра: языки/инструменты —
раз в квартал, практики — раз в полгода.
